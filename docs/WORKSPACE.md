# DubTool workspace document (AGU10 task 7.4)

Every folder and file that can appear in the **project folder** and in the
**build root**, what creates it, who needs it, how to regenerate it, and
whether deleting it is safe. Written from the code —
`src/dubtool/workspace.py` (build root, AGU10 task 1), `src/dubtool/job.py`
(job folders), `packaging/build_exe.ps1` (build), `src/dubtool/app/paths.py`
(installed-app data). `scripts/disk_report.py` compares the real top-level
entries against `DOCUMENTED_ENTRIES` in `src/dubtool/disk_report.py` and
flags anything this file does not describe.

Generated data lives **outside** the project by default
(`<build root>` = `<project parent>/<project name>_build`, override with
`DUBTOOL_BUILD_ROOT`).

## Build root (AGU10 task 1, `src/dubtool/workspace.py`)

| Entry | Created by | Needed by | Regenerate | Regen time | Safe to delete |
|---|---|---|---|---|---|
| `venv-build/` | `packaging/build_exe.ps1` (recreated when the requirements hash changes) | exe build only | delete → next build recreates | ~5 min | yes |
| `pip-cache/` | build script env | faster builds | download again | n/a | yes |
| `build/` | PyInstaller work dir | nothing after promotion | any build | per build | yes |
| `dist/DubTool/` + `dist/*.zip` | build script (newest pair kept; `-ZipOnly` drops the folder) | testing, shipping | any build | per build | older pairs yes; newest yes (rebuild) |
| `vendor/` | user download (ffmpeg.exe, fonts) | build packaging + PyAV-fallback probing | re-download | manual | no (third-party, no auto-regen) |
| `jobs/` | dub runs from source | resume | run again | minutes | yes when finished |
| `models/` | voice models if relocated | Piper runs | re-download | ~80 MB | no (models) |
| `hf-cache/` | sanitized-verification runs (`HF_HOME`/`HF_HUB_CACHE`, AGU10 3.1) | repeat verifications (no re-download) | re-download Whisper model | ~484 MB | yes (costs one re-download) |
| `models-cache/` | `DUBTOOL_MODELS_DIR` override for verification runs | same | re-download | n/a | yes |
| `sample_output/` | headless sample runs | e2e evidence | next run | minutes | yes |
| `screenshots/` | build screenshot step | README images | `-Screenshot` step | ~1 min | yes |
| `inventory/` | `scripts/disk_report.py` output history | trend comparison | rerun | minutes | yes |
| `logs/` | every agent/tool log (AGU10 1.5) | debugging, reports | next tool run | n/a | yes (keep the review's cited logs) |
| `tmp/` | sanitized homes and temp files (removed after each run) | verification only | n/a | n/a | yes (the run cleans itself) |

`<build root>` never lives inside the project folder — `workspace.build_root()`
refuses that (`src/dubtool/workspace.py`), which is what kept the project at
4.4 GiB before Update 10.
